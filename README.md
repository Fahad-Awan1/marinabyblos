# Marina Byblos Hotel: website redesign

Home page redesign built with Vite, GSAP (ScrollTrigger + SplitText), Lenis smooth scroll and OGL (WebGL).

```bash
npm install
npm run dev       # dev server → http://localhost:5180
npm run build     # production build → dist/
npm run preview   # serve the build → http://localhost:4173
```

Only the home page is redesigned so far. Nav links scroll to home-page sections; links to
pages that aren't rebuilt yet (gallery, offers, menus, terms) go to the live site. Unknown
paths return 404 locally instead of silently showing the home page.

## Structure

- `index.html`: all page content and markup (SEO meta + Hotel JSON-LD)
- `src/styles/main.css`: design tokens (sand / marina night / sunset) and section styles
- `src/main.js`: boot order (pinned scenes are created in page order, nav last)
- `src/js/loader.js`: sunset loader (rising sun + rolling counter, sun opens into the hero)
- `src/js/hero.js`: letter-convergence title, video tucks into a rounded card on scroll
- `src/js/scenes.js`: pinned scenes: neighbourhood collage, 3D showreel, rooms, dining fan
- `src/js/story.js`: facilities chapters (circle wipes, chapter counter, dash ticker)
- `src/js/reveals.js`, `odometer.js`, `sections.js`, `amenities.js`, `marquee.js`, `nav.js`, `cursor.js`, `booking.js`
- `src/js/gl/images.js`: WebGL room cards: corner peel, bend, hover ripple (desktop only, lazy-loaded)
- `public/topo.svg`: contour-line texture, generated by `node scripts/gen-topo.mjs`
- `public/media/`: hero and showreel videos (from the current site)

## Images

Images are written as `<img data-wix="<media id>" data-ar="4/5" data-max="1200">`.
`vite.config.js` expands them into a responsive AVIF `srcset`. Every variant is self-hosted
from `public/img/` (downloaded once from the Wix media library), so the site never depends
on the Wix CDN at runtime. Any variant missing locally falls back to the CDN.

After adding or changing an image in `index.html`, run `npm run images` to download its
variants (it drives a local Chrome; set `CHROME=<path>` if it isn't found).
